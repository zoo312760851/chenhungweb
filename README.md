# Chen-Hung Engineer Portfolio

A polished, bilingual, responsive personal portfolio designed for GitHub Pages.

## Highlights

- Professional dark engineering aesthetic
- Traditional Chinese / English language switch
- Dark / light theme switch
- Responsive layouts for desktop, tablet, and phone
- Animated terminal, scroll reveal, mobile navigation
- Keyboard command palette: press `/` or `Ctrl/Cmd + K`
- No frameworks, package installs, or external assets required

## Customize first

Open `index.html` and replace these placeholders:

1. `your.email@example.com`
2. `github.com/your-username`
3. `linkedin.com/in/your-profile`
4. Any project descriptions, skills, and dates that you want to revise

Search for `替換` in `index.html` to find the contact placeholders quickly.

## Publish with GitHub Pages

1. Create a new **public** GitHub repository, for example `portfolio`.
2. Upload all files in this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. GitHub will provide a URL such as `https://USERNAME.github.io/portfolio/`.

For a root personal site, name the repository `USERNAME.github.io`.

## Local preview

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
